One tap, no install

Bookmark button

Start the help bar on any page with one tap. Nothing to install, and it works on phones too.

On a computer

Show your bookmarks bar (Ctrl+Shift+B), then drag this button onto it:

Digital Bridge help

Then, on any page with a form, click Digital Bridge help in your bookmarks bar.

On a phone, or without dragging

  1. Press Copy the code.
  2. Bookmark this page, then edit the bookmark: name it Digital Bridge help and paste the code as its address (URL).
  3. On any page, type Digital Bridge help in the address bar and tap the bookmark.

Some sites, such as LinkedIn, block scripts started this way. Use the browser extension there. See all ways to install.
